# AGENTS.md

This file is for any coding agent other than Claude. It intentionally does
not duplicate content: everything an agent needs — commands, the four
surfaces, where the data comes from, known gotchas, and conventions — is in
[`CLAUDE.md`](./CLAUDE.md). Read that file; it applies regardless of which
agent is reading it.

For vocabulary specific to stdlib's package layout and naming (package,
namespace, variant, family, edge kinds, tags), see [`CONTEXT.md`](./CONTEXT.md).
