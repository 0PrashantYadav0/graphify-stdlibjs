# docs/superpowers

The `plans/` and `specs/` files in this directory are the original planning
and design documents written before the work tracked in GitHub issue #1.
They are kept for history and are superseded by how the codebase actually
turned out — some of what they describe (naming, colours, breakpoints, ARIA
roles) was changed during implementation and no longer matches the shipped
app. Nothing in `src/`, `scripts/`, or the other agent-facing docs
references them. For current truth about this project, see `CLAUDE.md`,
`CONTEXT.md`, and `docs/adr/`.
